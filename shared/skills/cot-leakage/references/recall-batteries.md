# 想起用パターン集

分類ごとの探索プローブ。ヒットは全て意味で判定する。パターンは取りこぼす前提であり、スコープ内で最も濃い文章（モジュール JSDoc・README・PR 本文）はパターンを持たずに素読みもする。

## 呼び出し規則

- `--hidden --glob '!.git/**'` を付ける。ripgrep は既定でドットディレクトリを飛ばすため、`.github/` や `.agents/` 配下の漏れが最大の取りこぼしになる。
- 除外は最後に置く。後から足す include が除外を打ち消さないようにする。自分の較正材料を引用する本スキルのディレクトリと、記録済みフィクスチャ・スナップショットも除外する。
- 自然文の行には `-i` を付ける。文頭の大文字（`This PR adds…`）を拾うため。コード寄りのパターン行は大文字小文字を区別したままにする。`-i` は `\bT\d\b` や `\bP-I\b` をノイズに変える。
- 完全な語句で囲む。`\b本 ?PR\b` は「本 PR で追加」に当たり、「本プロジェクト」「本プロセス」に当たらない。
- **ゼロヒットのパターンは、既知の陽性と一致するまで何も証明しない。ノイズの多いパターンは、近い偽陽性を弾けるまで何も証明しない。** どちらも先に較正する。
- 言語の混入は反対側の面に当てる。日本語の文章に残った英語の説明文を探す。ASCII の断片を無条件に探すとコードと識別子で溢れるため、行内の英単語の連なりで絞る。

## 日本語バッテリー

```sh
# 1. 死んだ設計セッション参照
rg -n --hidden '\(decision \d|\(監査 ?[A-Z]\d|設計(書)? ?v?\d+ ?§|計画 ?§|設計台帳|\(B ?裁定|フェーズ ?[A-Z0-9]' \
  --glob '!.git/**' .
rg -n --hidden '\bT\d\b|\bW\d\b|\bP-I\b' --glob '!.git/**' .

# 2. スタック・PR 視点
rg -n --hidden '本 ?PR|このスタック|後続の? ?PR|このブランチ|前のコミット|このコミット' \
  --glob '!.git/**' .

# 3. 変更の物語と版スタンプ
rg -n --hidden '以前は|昔は|かつて|もう使わない|使われなくな|旧版|古い ?[A-Za-z]|削除された|追加された|変更された|今は' \
  --glob '!.git/**' .
rg -n --hidden 'この版|本版|このカット|現時点|当面|ロードマップ|今のところ|\bv[0-9]\b' \
  --glob '!.git/**' .

# 4. レビューの振り付け
rg -n --hidden 'レビューで却下|レビュー指摘|レビュアー|レビューラウンド|(この|本)ノートの ?v[0-9]|指摘対応' \
  --glob '!.git/**' .

# 5. レビュアー宛ての自己弁護
rg -n --hidden '安全である|正しい。なぜなら|単に|だから問題ない|で十分|問題ない' \
  --glob '!.git/**' .

# 6. 復唱・導出の実況
rg -n --hidden 'まず.*次に|手順は次のとおり|このテストは.*し.*し' \
  --glob '!.git/**' .

# 7. ヘッジと計画の残骸
rg -n --hidden 'とりあえず|おそらく|たぶん|だろう|はず|当面は|十分だろう|足りるはず' \
  --glob '!.git/**' .

# 8. 執筆言語の混入（日本語面に残った英語の説明文）
rg -n --hidden '[ぁ-んァ-ヶ一-龠]' --glob '*.md' --glob '!.git/**' . \
  | rg '[A-Za-z]{2,}( +[A-Za-z]{2,}){3,}'
```

## 英語バッテリー

```sh
rg -n --hidden '\(decision \d|\(audit [A-Z]\d|design §|plan §|design ledger|\(B ruling|\bP-I\b|\bW\d\b|\bT\d\b' \
  --glob '!.git/**' .
rg -n --hidden -i '\bthis PR\b|\bthis branch\b|\bthis stack\b|\blater PRs?\b|\bprevious commits?\b|\bthis commit\b' \
  --glob '!.git/**' .
rg -n --hidden -i '\bused to\b|\bno longer\b|\bpreviously\b|\bthe old\b|\bwas renamed\b|\bwas moved\b' \
  --glob '!.git/**' .
rg -n --hidden -i '\bv1\b|this cut|\bcut \d|\btoday\b|\bfor now\b|roadmap' --glob '!.git/**' .
rg -n --hidden -i 'rejected in review|review round|reviewer|as of v\d' --glob '!.git/**' .
rg -n --hidden -i 'probably |should be enough|should suffice|it simply|is safe —|is safe --' --glob '!.git/**' .
rg -n --hidden '§\d' --glob '!.git/**' .
```

除外は実際のスコープに合わせて末尾へ足す:

```sh
--glob '!vendor/**' --glob '!node_modules/**' \
--glob '!.agents/notes/archived/**' --glob '!shared/skills/cot-leakage/**'
```

## 較正の対

難しいパターンは、陽性と陰性の対で先に試す。片方だけでは何も証明しない。

| パターン | 既知の陽性 | 弾くべき陰性 |
|---|---|---|
| `\bused to\b` | `Colors used to come from tokens.` | `The key used to sign requests.`（手段） |
| `以前は` | 「色は以前トークンから来ていた」 | 「以前から変わらない」（現状の継続） |
| `\b本 ?PR\b` | 「本 PR で追加する」 | 「本プロジェクト」「本プロセス」 |
| `\bv[0-9]\b` | 「バッチ描画は v1 では同期」 | `/v1/chat`（プロトコル） |
| `\bT\d\b` | 「シェル（T4）」 | `T0` を含む識別子を拾わないよう語境界で囲む |
| バッテリー8 | 「デフォルトでは falls back to the previous value を返す」 | 「レンダラは client 側で動く」（英単語2語の連なり） |

バッテリー8は英単語4語以上の連なりだけを拾う。短い未翻訳片はパターンでは取れないので、分類8が疑われる面は素読みで補う。

## 偽陽性族

判定して残した族。次回も同じ形で出る。

- **手段の「使って」/ instrumental "used to"** — 「リクエストの署名に使う鍵」は手段であり時間ではない。時間の形は前に主語の状態がある（「色は以前〜から来ていた」）。
- **実行時の old/new** — 「古い接続が drain してから新しい接続が受ける」は引き継ぎ中の生きたオブジェクト。変更の物語の禁止はリポジトリの状態についてであり、ライフサイクルの語彙ではない。
- **プロセス文書の「PR」** — PR の手順を説明する文書は「PR」と正当に書く。禁止は、ある1つの PR の視点を採用した文書についてである。
- **`v1` がプロトコルかパスの一部** — `/v1/chat` やワイヤ形式の名前は識別子であり版スタンプではない。
- **所有者がコミット済みの `§N`** — 外部規格（`RFC 9110 §10.1.5`）と、§ 番号を所有する自リポジトリのコミット済み文書は節で引用してよい。
- **実行時の「今日」と記録済みタイムスタンプ** — 現在日付を問うプロンプトやテストは自然な時刻を使う。記録済みの CLI 出力はその声のまま残す。
- **「現在の」「今の」が現状の記述** — 「現在の実装は〜」は変更の物語でないことがある。過去の状態と対比しているかで判定する。
- **代替案節の「却下」** — 設計文書の「検討した代替案」の中の却下は正規の置き場であり、レビューの振り付けではない。
- **手順書の「まず…次に」** — 実際の操作手順は復唱ではなく手順である。コードやテスト本体の言い直しになっているかで判定する。
- **テストの記述** — 「2往復でログは4件になる」のような検証の主張は、テスト本体の実況ではない。

ヒットの意味判定は、削ったときの巻き添えを防ぐ。とくに issue 参照・`measured`・suppression の理由・公開 API の契約は、漏れと誤判定されやすい。
