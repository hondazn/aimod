# 空文の一覧と置換先

論点を増やさず「ちゃんと書いている感」だけを付ける言い回し。書き上げたあとに検索して潰す。

## 予告と総括

| 使わない | どうするか |
|---|---|
| 重要なのは〜である | 主張をそのまま書く |
| 本章では〜を扱う / 探求する | 扱う内容を書く。型が解説なら、態度を帯びた一文なら可 |
| ここでは〜について見ていく | 削る |
| まとめると / 要するに | 直前の言い換えにしかならないなら削る。圧縮した一文を残すなら可 |
| 〜に他ならない | 「〜である」 |

## 姿勢の宣言

| 使わない | どうするか |
|---|---|
| 正面から扱う / 回収する / 見る | 「扱う」「回収する」「見る」 |
| しっかりと / きちんと | 削る。何をどこまでやるかを具体的に書く |

## 空虚な形容

「不可欠」「核心的」「鍵となる」「根本的な」— 主張の中身を説明せず強調だけする。何がどう効くかを書く。

「多角的」「包括的」「総合的」— 何をどう見たかを書いていない。見た対象を列挙する。

## 空虚な動詞

「掘り下げる」「深掘りする」「言語化する」— 何をどう書いたかを示さずに終わる。書いた内容そのものを置く。

「触れる」「言及する」— 一段落で済ませるだけなら、その一段落を書く。

## 接続の型

「〜において」「〜という側面から」「〜の観点から」— 新情報がないなら削る。

「さらに」「また」「加えて」の連打 — 並列なら一文にまとめる。

## 弱い緩和と中身のない強調

「〜と言えるだろう」「〜かもしれない」— 根拠なく主張を弱めている場合だけ削る。
推量・仮定・読み手の疑念・作中人物の認識を表すなら残す。

「非常に」「極めて」「大いに」— 削るか、程度を数値・事例に置き換える。

## 冗長表現

| 使わない | どうするか |
|---|---|
| 〜することができます | 〜できます |
| 〜という形になります | 〜です |
| 〜を行う | 〜する |
| 〜についての | 〜の |
| 基本的には / 一般的に | 削るか、具体的な条件に置き換える |
| それ自体はよいことである | 削る（接続や評価のためだけの文） |

## 判定

上の表に無い語でも、問いは同じ。

- **その文が読み手に何をさせるか、何を知らせるかを言えるか。** 言えないなら削る
- **その文を他プロジェクトのドキュメントにそのまま置けるか。** 置けるなら、この文書について何も言っていない
